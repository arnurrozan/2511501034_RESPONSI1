# Dashboard Admin Toko Online (Responsi 1 - Pemrograman Fullstack)

Studi kasus 4: **Dashboard E-Commerce / Manajemen Produk**.
Aplikasi CRUD client-side (tanpa backend); data disimpan di state React (array of objects).

## Teknologi
HTML semantik, CSS (variabel, media query, transisi), Bootstrap 5, JavaScript dasar,
jQuery (animasi sidebar & tabel), React 19 + Vite.

## Fitur
- Tambah, lihat, ubah, hapus produk
- Pencarian nama dan filter kategori
- Status stok otomatis: Aman / Menipis / Habis
- Harga, diskon, dan harga akhir
- Kartu statistik ringkasan
- Responsif (desktop, tablet, mobile)

## Cara Menjalankan
```bash
npm install
npm run dev
```
Buka alamat yang tampil di terminal (biasanya http://localhost:5173).

## Build Produksi
```bash
npm run build
```
